# IT Support Home Lab

## Overview

This repository documents my practical IT support home lab, where I develop and demonstrate troubleshooting and technical support skills using my own computer equipment and software.

The purpose of this project is to gain practical experience alongside my Level 3 Information Technology qualification and university studies, while preparing for entry-level IT Support and Help Desk roles.

## Objectives

- Develop systematic IT troubleshooting skills
- Practise Windows troubleshooting and system administration
- Develop basic networking knowledge
- Practise hardware and device troubleshooting
- Practise software installation and troubleshooting
- Learn useful Windows command-line tools
- Simulate realistic IT support scenarios
- Document troubleshooting processes and resolutions
- Build evidence of practical technical skills
